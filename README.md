# ShiftDrop

Конвертер файлов для Windows в духе macOS-приложения Tangerine: **зажал Shift, потащил файл — появилось круговое меню, отпустил на нужном формате**. Результат кладётся рядом с исходником, оригинал не трогается. Всё работает локально, без интернета (кроме однократной загрузки ffmpeg).

## Как пользоваться

| Действие | Что происходит |
|---|---|
| **Shift + перетащить** файл(ы) | Круговое меню форматов под курсором |
| **Shift + Ctrl + перетащить** (или нажать Ctrl уже во время перетаскивания) | Меню инструментов: сжать, обрезать, склеить… |
| Отпустить в **центре** меню или увести курсор далеко | Отмена, файл не тронут |
| **Правый клик** по файлу → «Конвертировать… (ShiftDrop)» | То же меню, выбор кликом; клик в центр — переключить форматы/инструменты |
| Значок в трее | Вкл/выкл, пункт в Проводнике, автозапуск, загрузка ffmpeg, журнал |

> В Windows 11 пункт контекстного меню находится в «Показать дополнительные параметры» (Shift+F10).

Можно тащить сразу несколько файлов: меню строится по типу первого, файлы других типов пропускаются.

## Что умеет

| Тип | Форматы | Инструменты (Ctrl) |
|---|---|---|
| Картинки (JPG, PNG, WEBP, HEIC, AVIF, BMP, GIF, TIFF, ICO, PSD, TGA) | JPG, PNG, WEBP, PDF, BMP, GIF, TIFF, ICO, AVIF | Сжать, Без EXIF, 50%, Повернуть, Обрезать (окно с выделением), В один PDF |
| PDF | JPG, PNG (каждая страница, 150 dpi) | Склеить несколько, Разбить по страницам |
| Видео (MP4, MKV, AVI, MOV, WMV, WEBM, …) | MP4, MKV, WEBM, MOV, AVI, GIF, MP3, WAV | Сжать, 720p, Без звука, Без метаданных |
| Аудио (MP3, WAV, FLAC, OGG, M4A, AAC, WMA, OPUS, …) | MP3, WAV, FLAC, OGG, M4A, OPUS | Сжать (MP3 128k), Без метаданных |
| Документы (DOC, DOCX, ODT, RTF, TXT) | PDF, DOCX, ODT, RTF, TXT | — |
| Таблицы (XLS, XLSX, ODS, CSV) | PDF, XLSX, ODS, CSV (`;`, UTF-8) | — |
| Презентации (PPT, PPTX, ODP) | PDF, PPTX, ODP | — |

## Движки

- **Картинки** — [Magick.NET](https://github.com/dlemstra/Magick.NET) (ImageMagick), встроен.
- **PDF** — [Docnet.Core](https://github.com/GowenGit/docnet) (PDFium), встроен.
- **Видео/аудио** — `ffmpeg.exe`. Ищется рядом с exe, в `%LOCALAPPDATA%\ShiftDrop\ffmpeg\` и в `PATH`. Если не найден — при первом использовании предложит скачать сборку [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) (~150 МБ). Для офлайн-машин просто положите `ffmpeg.exe` рядом с `ShiftDrop.exe`.
- **Офис** — установленный MS Office (через COM: Word/Excel/PowerPoint) или, если его нет, LibreOffice в headless-режиме (с отдельным профилем, чтобы не мешать открытому LibreOffice).

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) на Windows x64.

```cmd
build.cmd
```

Результат — папка `publish\` с `ShiftDrop.exe` (self-contained, .NET ставить на целевые машины не нужно). Папку можно положить куда угодно, например в `%LOCALAPPDATA%\Programs\ShiftDrop`, и запустить exe один раз.

Или через GitHub: запушить репозиторий — workflow `.github/workflows/build.yml` соберёт архив `ShiftDrop-win-x64.zip` в артефактах; при пуше тега `v*` — прикрепит к релизу.

## Что пишется в систему

Только HKCU, права администратора не нужны:

- `HKCU\Software\Classes\SystemFileAssociations\.<ext>\shell\ShiftDrop` — пункт контекстного меню для поддерживаемых расширений;
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ShiftDrop` — автозапуск;
- `HKCU\Software\ShiftDrop` — флажки настроек;
- `%LOCALAPPDATA%\ShiftDrop\` — журнал и ffmpeg.

Удаление: снять галочки в трее (или удалить ключи выше), выйти и удалить папку.

## Как это устроено

```
App.xaml.cs            — единственный экземпляр, трей, первый запуск, аргументы (--menu "файл")
Core/MouseHook.cs      — глобальный WH_MOUSE_LL
Core/DragWatcher.cs    — ЛКМ зажата + сдвиг > 12 px + Shift → ставит под курсор окно-приёмник
UI/RadialWindow.cs     — круговое меню: drag-режим (OLE drop target) и click-режим
Core/Menus.cs          — какие действия показывать для типа файла
Core/Jobs.cs           — очередь задач, прогресс, отмена
UI/ToastWindow.cs      — уведомление с прогрессом и кнопкой «Показать»
Engines/*              — Image / Pdf / Media(ffmpeg) / Office
Core/Ipc.cs            — именованный канал: Проводник запускает процесс на каждый файл, всё собирается в одно меню
```

Ключевая хитрость drag-режима: окно-приёмник появляется **невидимым** (альфа 1/255) — так оно получает OLE `DragEnter`, но ничего не показывает. Меню проявляется, только если в `DragEnter` пришли файлы (`CF_HDROP`). Если Shift+тащат текст, окно или выделение — пользователь ничего не увидит, а окно спрячется при отпускании кнопки или если курсор уйдёт от центра. На drop мы всегда отвечаем `Copy`, поэтому Проводник не перемещает исходник, даже если Shift означал «переместить».

## Известные ограничения

- Не работает поверх окон, запущенных от администратора (UIPI) — для этого ShiftDrop тоже надо запускать от администратора.
- Виртуальные файлы (вложения Outlook, содержимое zip без распаковки) не поддерживаются — у них нет пути на диске.
- Конвертация в HEIC не предлагается (нет надёжного энкодера); HEIC → JPG/PNG работает.
- PDF → DOCX нет: качественно это делается только платными движками.
