Конвертер файлов для Windows: **зажал Shift, потащил файл — появилось круговое меню, отпустил на нужном формате.** Результат кладётся рядом с исходником, всё работает локально.

### Установка
1. Скачайте `ShiftDrop-win-x64.zip` ниже и распакуйте в постоянную папку (например, `%LOCALAPPDATA%\Programs\ShiftDrop`).
2. Запустите `ShiftDrop.exe` — появится значок в трее. .NET ставить не нужно.
3. Обновление: распакуйте новую версию поверх и запустите exe — старый экземпляр закроется сам.

### Что умеет
- **Картинки** (JPG, PNG, WEBP, HEIC, AVIF, ICO, TIFF, BMP, GIF, PSD) → JPG, PNG, WEBP, PDF, BMP, GIF, TIFF, ICO, AVIF; сжать, без EXIF, 50%, повернуть, обрезать, в один PDF
- **PDF** → JPG, PNG по страницам; склеить, разбить
- **Видео и аудио** (через ffmpeg, скачивается при первом использовании) → MP4, MKV, WEBM, MOV, AVI, GIF, MP3, WAV, FLAC, OGG, M4A, OPUS; сжать, 720p, без звука, без метаданных
- **Документы, таблицы, презентации** (через MS Office или LibreOffice) → PDF, DOCX, ODT, RTF, TXT, XLSX, ODS, CSV, PPTX, ODP
- **Архивы**: распаковать в папку, добавить к .zip / .7z (7z — если установлен 7-Zip)

**Shift + Ctrl** при перетаскивании — меню инструментов. Правый клик → «Конвертировать… (ShiftDrop)» — режим настраивается в трее.

### Изменения в этой версии
- Пункт в Проводнике: три режима — выключен / только конвертируемые файлы / все файлы и папки (по умолчанию — только конвертируемые, чтобы не мешать меню 7-Zip)
- Запуск новой версии закрывает уже работающую
- Версия видна в меню трея
